# Prompts Utilizados - Cronómetro con Prompt Engineering Avanzado

**Chatbot Usado**: ChatGPT-4
**Fecha**: 02/11/2025
**Metodología**: Basada en promptingguide.ai

## Técnicas de Prompt Engineering Aplicadas

### 1. Role Prompting
Definí al AI como "expert frontend developer with 10+ years experience"

### 2. Task Decomposition
Estructuré en secciones claras:
- Functional Requirements
- Technical Constraints
- Design Requirements
- Code Quality Standards

### 3. Few-Shot Learning
Incluí ejemplos de:
- Conversión de tiempo (125000ms → "00:02:05")
- Validación de inputs ("05:30" válido, "5:30" inválido)

### 4. Constraint Setting
Establecí límites claros:
- NO external CSS file
- NO placeholder code
- MUST work immediately

### 5. Output Formatting
Especifiqué exactamente: "Provide TWO complete code blocks"
